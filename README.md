# trickcal_note_revive

트릭컬노트 부활 프로젝트

## 남은 작업

- 익명 로그인 -> 구글 로그인 전환(구글 로그인 데이터 없으면 익명 데이터 덮어씌우기)
- 보드타입 클릭 시 저장 with Debounce
- 캐릭터 클릭 시 저장 with Debounce
- 보드락 추가
- 데이터 저장 및 체크 시 보드칸 ID 기준으로 변경
  - 이걸 고쳐야 3관에서 황크+보크 갯수 다 같은 두 칸이 동시에 켜지는 버그 해결 가능

## 후속 업데이트 계획

- 간단한 지표 수집
- 에러 발생 시 처리(토스트메세지?)
- 공지사항
- 오류 신고
- 보유캐릭터 변경 기능
- 황크계산기
